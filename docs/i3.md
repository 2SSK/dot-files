# The i3 session

i3 is the minimal session: **polybar** for the bar, **rofi** for every menu, **dunst** for
notifications and a light **picom**. There's no Quickshell here (sway keeps the shell: see
[desktop-shell.md](desktop-shell.md)). The keys are the same in both sessions: `keys.conf` is
sway's too, and where it asks the shell for something (`$shell <target> <function>`), i3's `$shell`
is `desktop i3`, which opens the matching rofi menu or runs the matching command. Colours and fonts
come from the desktop theme ([theme.md](theme.md)); a theme or font switch restyles all of it.

| Piece | Files | Restyled on a theme switch |
| --- | --- | --- |
| Bar | `.config/polybar/config.ini`, its modules `desktop bar <module>` | restarted (`polybar-msg cmd restart`) |
| Menus | `.config/rofi/config.rasi`, `desktop menu <name>` | the next time one opens |
| Notifications | `.config/dunst/dunstrc` | `dunstctl reload` |
| Compositor | the theme's `picom.conf` | (no colours in it) |
| Window colours | the theme's `i3.conf` | `i3-msg reload` |

The theme renders `polybar.ini`, `rofi.rasi` and `dunst.conf` and links them in as
`~/.config/polybar/theme.ini`, `~/.config/rofi/theme.rasi` and
`~/.config/dunst/dunstrc.d/90-theme.conf`.

## Bar

Minimal, after the v1 bar: words rather than icons, the label in the accent and the value beside
it, in the font collection's monospace. Left: the workspaces (the one you're on on a lighter ground,
underlined in the accent), then `scratch 2` while the scratchpad holds windows (a click shows or hides it). Centre:
the date and time; `rec 01:23` while recording (a click stops it). Right: `cpu 4%`, `mem 46%`
`bat 80%` (`chr` while charging, the number red when low: `power.batteryLow`) and ⏻ (the power
menu). Notifications have no place on it: `$mod+n` opens them. One bar per screen;
`$mod+Shift+b` hides it. The items whose label mixes colours (cpu, mem, power) are defined in the
rendered `theme.ini`: polybar takes a reference only as a whole value.

## Keys and menus

| Key | Opens |
| --- | --- |
| `$mod+d` | apps (`desktop menu apps`) |
| `$mod+;` | emoji: Enter copies one |
| `$mod+Shift+f` | files under home: Enter opens one |
| `$mod+Shift+y` | themes: Enter applies one, Alt+m switches dark and light |
| Alt+Tab (hold Alt) | windows, the last one first: Tab steps, letting go of Alt switches |
| `$mod+minus` / `$mod+Shift+Return` | show or hide the scratchpad group / add the window to it (`desktop scratch`) |
| `$mod+Shift+c` | the clipboard's history: Enter copies one back, Alt+p pins, Alt+d forgets, Alt+c clears |
| `$mod+Shift+p` | wallpapers, a grid of previews: the arrows move through it, a page at a time; Enter sets one (matugen's colours follow) |
| F12 | capture: r w s screenshot a region, the window, the screen; R W S record them; t copies text; c picks a colour |
| Ctrl+F12 / Shift+F12 | screenshot a dragged region / the screen, no menu |
| `$mod+F12` | stop a recording (else record the screen) |
| `$mod+n` | notifications: Enter shows one again, Alt+d dismisses, Alt+c clears, Alt+n do-not-disturb |
| `$mod+p` | power, a row of five tiles, one large centred icon each (lock, sleep, log out, reboot, shut down), no names; 1–5 or ← → pick, Enter runs; log out, reboot and shut down ask for a second press (the line under the tiles says so) while `power.confirm` is on |
| `$mod+Shift+s` | settings: theme, dark or light, font collection, wallpaper, keys |
| `$mod+Shift+/` | every key binding; Enter runs one |
| `$mod+Shift+t` / `$mod+Shift+n` | to-dos / notes ([notes.md](notes.md)) |
| F1–F6, media keys | volume, microphone and brightness (`desktop level`): one card with a bar |

## Notifications

dunst, at the top right, themed; its user service stays masked so it never starts on sway (where
the shell shows notifications). Critical ones stay until clicked; a click runs the default action.
The history keeps 50; the volume and brightness cards stay out of it.

## Clipboard history

`desktop cliphist keep` (started with i3) follows `desktop clipboard watch` and keeps each copy:
text, images and files. With `clipboard.persist` on it uses the shell's own file
(`~/.local/state/desktop/clipboard/history.json`) and pins, so sway and i3 share one history; off,
it's in RAM. `clipboard.max`, `days` and `images` limit it as they do the shell's.

## Screen recording

`desktop record start|stop|toggle` runs `desktop capture record` in the background into
`~/Videos/Recordings` (with the microphone when `audio.recordMic` is on); the bar's dot shows it
running, and the saved file is announced.

## picom

Light on purpose: vsync (no tearing), rounded corners and translucency (kitty's 90 %), nothing else:
no blur, shadows, fades or animations. Fullscreen windows bypass it. It's started by i3 alone (the
package's XDG autostart entry is hidden in `~/.config/autostart/picom.desktop`: two at login raced);
if it ever falls back to xrender, why is in `$XDG_RUNTIME_DIR/picom.log`.

## Screens

`desktop displays` arranges screens as sway's outputs config does: the laptop panel at the left,
each connected external screen to the right of the one before at its preferred mode; an unplugged
screen is turned off, the wallpaper is drawn again across them, and the bar restarted so each screen
has one. i3 starts it in `watch` mode, which listens for plug and unplug events (`udevadm monitor`)
and arranges again. Workspaces 2, 3, 9 and 10 live on the external screen (HDMI-1, else DP-1), the
rest on the panel, as on sway.

## Touchpad

`desktop input`, run when i3 starts or reloads, sets the touchpad up as sway's input config does:
tap to click, tap and drag, natural two-finger scrolling, clickfinger, no touchpad while typing.
Scrolling on X is twice as fast as on Wayland by default, so it's slowed: one scroll step per 45
pixels of finger movement (`DESKTOP_SCROLL_DISTANCE`, 10–50).

## Lock and idle

xss-lock runs `desktop lock` (i3lock-color over the blurred wallpaper: a large 24-hour clock in the
font collection's display font, the date and a quiet hint in its monospace, a ring
that lights up as you type) on `loginctl lock-session`, a closed lid and before sleep; asked
again while locked, it waits on the lock showing rather than stacking another. `desktop idle apply` (at login) sets X's screensaver and DPMS timers
from `shell.json`'s `idle` minutes: the screen dims (`desktop idle dim`), then locks, then switches
off. The password prompt for admin actions is polkit-gnome's.
